# Códigos estáveis de validação

Os códigos abaixo fazem parte dos contratos públicos de validação e auditoria.

| Código | Descrição |
| --- | --- |
| `audit.autorizacao_ausente` | Autorização ausente |
| `audit.autorizacao_vencida` | Autorização vencida |
| `audit.carteirinha_ausente` | Carteirinha ausente |
| `audit.carteirinha_inativa` | Carteirinha inativa |
| `audit.carteirinha_vencida` | Carteirinha vencida |
| `audit.data_ausente` | Data do atendimento ausente |
| `audit.operadora_divergente` | Operadora divergente |
| `audit.procedimento_ausente` | Procedimento ausente |
| `audit.procedimento_fora_da_tabela` | Procedimento fora da tabela da operadora |
| `audit.tabela_fora_de_vigencia` | Tabela fora de vigência |
| `audit.tabela_sem_procedimentos` | Tabela sem procedimentos |
| `audit.valor_nao_positivo` | Valor não positivo |
| `guia.carteirinha_ausente` | Carteirinha ausente |
| `guia.executante_ausente` | Dados do executante ausentes |
| `guia.sequencial` | Sequencial de itens inválido |
| `item.valor_divergente` | Valor do item divergente |
| `item.valor_zerado` | Valor do item ausente ou zerado |
| `lote.acima_do_teto` | Lote acima do limite de guias |
| `lote.caractere_invalido` | Caractere incompatível com ISO-8859-1 |
| `lote.estrutura` | Estrutura do lote inválida |
| `lote.guia_duplicada` | Número de guia duplicado |
| `lote.hash_divergente` | Hash do epílogo divergente |
| `lote.valor_total_geral` | Total geral divergente |
| `lote.vazio` | Lote sem guias |
| `regra.combinacao_proibida` | Combinação proibida pela operadora |
| `regra.max_itens` | Limite de itens da operadora excedido |
| `regra.obrigatorio` | Campo obrigatório ausente |
| `regra.padrao` | Valor fora do padrão da operadora |
| `regra.valores` | Valor não permitido pela operadora |
| `tuss.fora_de_vigencia` | Código TUSS fora de vigência |
| `tuss.inexistente` | Código TUSS inexistente |
| `versao.divergente` | Versão informada difere do XML |
| `versao.nao_detectada` | Versão TISS não detectada |
| `versao.nao_suportada` | Versão TISS não suportada |
| `xml.doctype` | DOCTYPE não permitido |
| `xml.encoding` | Codificação XML inválida |
| `xml.malformado` | XML malformado |
| `xsd.atributo` | Atributo inválido |
| `xsd.elemento_ausente` | Elemento obrigatório ausente |
| `xsd.elemento_inesperado` | Elemento inesperado |
| `xsd.enumeracao` | Valor fora da enumeração |
| `xsd.outro` | Erro de validação XSD |
| `xsd.padrao` | Valor fora do padrão |
| `xsd.tamanho` | Tamanho inválido |
| `xsd.tipo` | Tipo inválido |
