# Pacotes de regras

Pacotes JSON seguem [`schemas/rules.schema.json`](../schemas/rules.schema.json)
e usam as primitivas documentadas em
[`docs/regras-operadora.md`](../docs/regras-operadora.md).

Use dados sintéticos. Inclua uma fonte publicada antes de marcar um pacote como
oficial. Não inclua código executável, dados pessoais ou credenciais.
